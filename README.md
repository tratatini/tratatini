#### What I've built

| Project | What it does |
| --- | --- |
| AI interview notes | Call transcript → structured candidate note, reviewed by a recruiter, posted to the ATS. ~20 s and < $0.01 per note. |
| Silver-medalist re-engagement | Daily job keeps a pool of past finalists and adds the best fits to every new vacancy automatically. |
| Sourcing agent | Ranked shortlist of ~20 candidates per vacancy with reasons and draft messages. |
| HR & recruiting analytics | Live hiring-funnel dashboard behind single sign-on. |
| Live org chart | Built from HR system, team pages and time split, with automatic gap checks. |
| Outreach & sequences | Templates, scheduled sends and sequences, each touch logged in the ATS. |

These tools were built for my employer, so their code is private. The portfolio explains the approach without company data.

#### How I work

- One source of truth: tools read from and write back to the ATS.
- Push, don't ask: results land in the pipeline without anyone requesting them.
- AI drafts, people decide: a recruiter reviews before anything reaches a candidate.
- Private by default: SSO, secrets in a vault, no candidate data in code or logs.
